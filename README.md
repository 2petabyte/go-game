# Go Spel 🎌

A browser-based Go (weiqi/baduk) board game, built as a single self-contained HTML file — no dependencies, no build step.

## Play

Open `index.html` in any browser, or play online: https://2petabyte.github.io/gogame/

## Features

- Traditional Go board (19×19)
- Two-player local play (black & white stones)
- Pure HTML/CSS/JavaScript

## Origin

Originally part of [2petabyte.github.io](https://github.com/2petabyte/2petabyte.github.io) under `gogame/`; moved into its own repository.
