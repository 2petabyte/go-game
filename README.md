# Go Game

A browser-based Go (weiqi/baduk) board game, built as a single self-contained HTML file — no dependencies, no build step.

## Play

Open `index.html` in any browser, or play online: https://2petabyte.github.io/go-game/

## Features

- Traditional 19×19 Go board with capturing and suicide-rule handling
- Two-player local play (black & white stones)
- Move history in standard notation (D4, Q16, ...) — copy to save a game, paste and reload to continue later
- Undo, pass, and captured-stone counters
- Pure HTML/CSS/JavaScript

## History

This is the English version. The original Swedish prototype ("Go Spel") is kept as the early version at [2petabyte.github.io/gogame/](https://2petabyte.github.io/gogame/), in the [portfolio repo](https://github.com/2petabyte/2petabyte.github.io/tree/master/gogame).
